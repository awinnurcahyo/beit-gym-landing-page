# Beit Gym Landing Page Demo

Landing page statis menggunakan HTML, CSS, dan JavaScript.

## Menjalankan di komputer
1. Ekstrak folder ZIP.
2. Buka folder `beit-gym-landing-page` di VS Code.
3. Buka `index.html` di browser, atau gunakan ekstensi Live Server.

## Sebelum dikirim ke Beit Gym
- Ganti `WHATSAPP_NUMBER` di `script.js` dengan nomor WhatsApp resmi.
- Ganti harga membership contoh di `index.html` dengan harga yang sudah dikonfirmasi.
- Ganti alamat, jam operasional, dan lokasi demo dengan informasi resmi.
- Ganti foto ilustrasi dengan foto asli Beit Gym yang mendapat izin untuk digunakan.
- Bagian peta saat ini berupa ilustrasi visual, bukan Google Maps interaktif.

## Publikasi di Vercel
1. Upload folder ini ke repository GitHub.
2. Di Vercel, pilih Add New Project dan import repository tersebut.
3. Framework Preset: Other. Build command dan output directory bisa dikosongkan untuk situs statis sederhana.
4. Deploy, lalu uji seluruh tautan terutama WhatsApp dan tampilan mobile.
